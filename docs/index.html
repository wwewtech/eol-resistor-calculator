SEOL vs DEOL Configurations

Unsupervised alarm loops cannot tell a cut wire from a quiet zone. Proper sizing ensures the panel can detect normal, alarm, tamper, and fault conditions.

Normal State (DEOL) = R1 + R2
Alarm State = R1 or R2 (depending on NO/NC)

Placement Rule

The resistor goes at the END of the loop (last device), never inside the panel. Panel-side placement blinds supervision to the field wiring.
