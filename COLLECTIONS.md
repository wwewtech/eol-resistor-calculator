  Hey HN!

  Security alarm technicians and low-voltage engineers frequently struggle with End-of-Line (EOL), Double-EOL (DEOL), and Triple-EOL (TEOL) resistor balancing. One miscalculated parallel resistor or cable resistance offset turns a normal zone into a spurious tamper alarm or undetectable wire fault.

  We built eol-resistor-calculator (https://github.com/wwewtech/eol-resistor-calculator), an open-source agent skill (SKILL.md) that provides deterministic alarm loop math:
  1. EOL, DEOL, and TEOL loop topology solver (Normal, Alarm, Tamper, Fault, Masking states)
  2. Voltage window threshold calculation across ADC pullup rails
  3. Loop wire resistance compensation (AWG 18-24 over long runs)
  4. Presets for major panels (DSC PowerSeries 5.6k, Honeywell Vista 2k, Texecom 4.7k/2.2k, Bosch 1k)
